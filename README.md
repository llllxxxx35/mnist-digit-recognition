\# MNIST 手写数字识别（PyTorch）



\## 任务

识别 28×28 灰度图片中的手写数字（0\~9）。



\## 数据

\- MNIST：训练集 60,000 张，测试集 10,000 张

\- 每张图 28×28 像素，灰度值 0\~255 归一化到 0\~1



\## 模型

两层全连接神经网络（MLP）：

\- fc1：784 → 128（ReLU 激活）

\- fc2：128 → 10

\- 参数总数：101,770



\## 训练

\- 优化器：Adam（学习率 0.001）

\- 损失函数：交叉熵（CrossEntropyLoss）

\- batch\_size：64，训练 3 轮

\- 训练损失：0.352 → 0.163 → 0.112



\## 结果

\- 测试集准确率：96.76%

\- 5 张测试图现场预测全部正确



\## 关键概念

\- 张量（Tensor）：PyTorch 数据格式，GPU 加速

\- 前向传播：数据流经网络打分

\- 反向传播（loss.backward）：计算每个参数的调整方向

\- 优化器（optimizer.step）：按梯度更新参数

\- epoch / batch：一轮完整训练 / 一次处理的样本数



\## 环境

Python 3.11, PyTorch 2.11 (CUDA 12.8), RTX 5070
